# 星晶のクロニクル (Star Crystal Chronicle)

マス目移動・ドット絵の **完全オープンワールドJRPG** です。ブラウザだけで動き、スマホ(縦・横)にも対応しています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・外部画像なし)。
GitHub Pages で公開すれば、スマホからURLでそのまま遊べます。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | 矢印 / WASD | 十字パッド |
| 決定・調べる・話す | Z / Enter / Space | A |
| キャンセル・ダッシュ(押しながら移動) | X / Shift / Esc | B |
| メニュー | C / M | MENU |

メニューやバトルのコマンドは、画面を直接タップしても操作できます。

## 特徴

- **シームレスなオープンワールド**: 512×512マスの世界(大陸・東の水晶の荒野・南東の南国の島々)に、町・家・ダンジョンがすべて置かれています。マップの切り替えはありません。建物に入ると屋根が消えて中が見え、洞窟では周りが暗くなります。
- **自由な攻略順**: 4つの神殿にある「封印の水晶」は、どの順番で集めてもかまいません。4つそろうと湖の魔王城へ渡れます。
- **カードバトル(スレスパ風)**: パーティ4人の固有カード各5枚と共通カード5枚の、計25枚がデッキになります。毎ターン、エナジー3で5枚引き、ターン終了で手札は全部捨てます。HPはパーティ全員の合計を共有し、戦闘後も持ち越します(クリスタルで全回復)。敵は次の行動を予告するので、ブロックで守ったり攻めたりを判断します。状態異常は筋力・敏捷・脆弱・脱力・毒・再生・トゲ。オートバトル、2倍速、山札と捨て札の確認、カードを使ったキャラのカットインもあります。パーティが4人未満だと、空き枠は「空白のカード」(効果なし)になります。
- **シンボルエンカウント**: 敵はフィールドに姿が見えていて、避けることもできます。近づくと追いかけてきます。
- **パズル**:
  - 倉庫番(岩押し): 岩をスイッチに乗せて扉を開けたり、穴を埋めて道を作ったりします。光る紋様を踏むと岩が元の位置に戻ります。
  - 謎解き・暗号: 方角の順番、3桁の暗号、スフィンクスのなぞなぞ、属性のなぞ。
  - 隠し宝: 石碑やNPCのヒントをたどって、地面を調べると見つかります。
- **ソシャゲ風ガチャ**(課金なし。星晶石は冒険で集めます):
  - 仲間キャラガチャ(全員かわいい女の子)とカードガチャ
  - 10連は★4以上が1枠確定。初心者10連は半額です。
  - ピックアップバナーでは、好きな★5を1人選んでピックアップにできます。ピックアップのキャラは、ほかの★5の8倍出やすくなります(限定バナーも同じルール。倍率は `js/data.js` の `PICKUP_WEIGHT`)。水晶を2つ集めると、限定★5「ステラ」のバナーが出ます。
  - レア度によって演出が変わり、ときどき途中でレア度が上がる演出が入ります。
  - 同じキャラが出ると限界突破(最大5凸)して、そのキャラの固有カードが強化されます。5凸でコスト2以上のカードがコスト-1。
  - 装備はありません。代わりに「カード召喚」で共通カードを集め、メニューの「デッキ」で共通カード5枠を入れ替えます。同じカードが出ると+1強化(最大+4)。
  - カードの威力はキャラのレベル(攻撃・防御・魔力)でも上がります。
  - 星晶石は宝箱、パズル、ボス討伐、ログインボーナスで手に入ります。
- **自動セーブ**: 戦闘・ガチャ・宝箱・謎解き・場所の移動のあとと、1分ごとに自動で保存します。各地のクリスタルでは全回復と転移ができ、ちず画面からも転移できます。
- **サブダンジョン**: 忘れられた遺構・潮騒の洞窟・結晶の迷宮。パズルと中ボスがいて、レアカードや星晶石が手に入ります。
- **レリック**: ★5キャラはそれぞれ固有のレリックを持ち、パーティにいるだけで戦闘中に発動します。凸で数値が上がります。

## ファイル構成

```
index.html
css/style.css
js/util.js     乱数・ノイズなどの共通関数
js/sprites.js  ドット絵の定義(タイル・キャラ・立ち絵・敵)。すべて文字列パターンで書かれています
js/data.js     キャラ・スキル・装備・敵・ガチャのデータ
js/map.js      ワールドの生成(町・家・ダンジョンの設計図)
js/field.js    フィールドの移動・描画・ギミック・敵シンボル
js/cards.js    カードの定義(固有カード・共通カード)と効果の計算
js/relics.js   ★5キャラのレリック
js/battle.js   カードバトル
js/gacha.js    ガチャ
js/menu.js     メニュー
js/story.js    ストーリー・NPC・イベント
js/state.js    セーブデータ・育成
js/sound.js    WebAudioで作る効果音とBGM
js/input.js    キーボードとタッチ操作
js/main.js     メインループ・タイトル
tools/         開発用の検証スクリプト(マップの到達性チェックと倉庫番ソルバ: node tools/test_map.js)
```

ドット絵は `js/sprites.js` の文字列を書き換えるだけで編集できます。

## コンテンツの追加方法

データの配列に項目を足すだけで、ガチャ・メニュー・図鑑・転移先の一覧にも自動で表示されます。一覧画面はタブ・並び替え・スクロールに対応しているので、項目が増えても使いやすいままです。

| 追加するもの | 場所 | 書き方 |
|---|---|---|
| キャラクター | `js/data.js` の `CHARS` | ステータス、スキル、見た目(`look`: 髪色・目の色・服の色・髪型・飾り)を書く。`gacha: true` でガチャに出る |
| キャラの固有カード | `js/cards.js` の `UNIQUE_CARDS` | `[名前, 'a'(アタック)/'s'(スキル), コスト, 効果]` を5枚。効果は `d8`(8ダメージ) `b6`(ブロック6) `D5`(全体5) などの短い記号で書く。奉仕(`!S`)、奉仕回数で伸びる防御無視ダメージ(`z`)、献身(`m`)、得たブロックと回復量で殴る(`q`)もある(ファイル先頭に一覧) |
| 共通カード | `js/cards.js` の `COMMON_CARDS` | 固有カードと同じ書き方に、レア度を足す。カード召喚に自動で出る |
| アイテム | `js/data.js` の `ITEMS` | `cat` でどうぐ画面のタブ(回復/状態/貴重品)が決まる。タブ自体は `ITEM_CATS` で増やせる |
| レリック | `js/relics.js` の `RELICS` | ★5キャラのIDをキーに、名前・説明と、戦闘開始時/毎ターン/アタック時/勝利時の効果を書く |
| ガチャのバナー | `js/data.js` の `BANNER_DEFS` | 表示条件(`show`)、ピックアップ(`pickup`)、属性フェス(`elem`)、提供割合、10連の価格 |
| 転移クリスタル | `js/map.js` の `WAYPOINTS` | 名前とおおよその座標。近くの道ばたに自動で置かれる |
| 小屋とNPC | `js/map.js` の `EXTRA_HOUSES` と `js/story.js` の `NPCS` | 小屋の位置と、どの町の門から道をつなぐか |

髪型は `long` `bob` `twin` `pony`、飾りは `ribbon` `tiara` `witch` `flower` `elf` `star` `hairpin` `cat` `band` `horns` `bunny` `halo` から選べます。
